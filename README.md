# QuickNotes

QuickNotes is a simple browser-based note-taking application built with HTML, CSS, and JavaScript. It allows users to create notes, organize them into Personal, Work, and Study categories, search for notes, and delete notes when they are no longer needed. The application uses the browser's localStorage to preserve notes across page refreshes.

## Features

- Add notes with text and categories.
- Organize notes into Personal, Work, and Study.
- Display each note's creation date and time.
- Validate empty notes and notes exceeding 200 characters.
- Delete individual notes.
- Search notes using case-insensitive keyword matching.
- Display the total number of notes.
- Save notes in localStorage so they remain available after refreshing.
- Responsive layout for smaller screens.
